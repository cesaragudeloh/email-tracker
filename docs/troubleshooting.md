# Troubleshooting MVP

Diagnosticar primero build/versión, proveedor y host, estado Activated, URL configurada
y requestId si existe. Nunca pegar tokens, códigos, credenciales o cuerpos en tickets.
Las lecturas AWS de esta guía corresponden al futuro entorno desplegado.

| Problema                               | Causa probable                                                                                              | Cómo diagnosticar / siguiente paso                                                                                                                                                                                                        |
| -------------------------------------- | ----------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Extensión no carga                     | Carpeta incorrecta, build incompleto o navegador no soportado.                                              | Ejecutar build; cargar `apps/extension/dist` completa en Chrome/Edge. Revisar errores del manifiesto/worker en página de extensiones; no cargar `public` ni source TS.                                                                    |
| Content script no detecta compose      | Pestaña anterior a recarga, host/DOM/idioma distinto o inline no reconocible.                               | Recargar extensión y pestaña, confirmar host y matches de manifest. Probar compose nuevo. Revisar selectores centralizados Gmail/Outlook y consola, sin copiar cuerpo ni datos personales.                                                |
| Track email no aparece                 | Adapter no encuentra editor o content script no cargado.                                                    | Confirmar `content.js` generado, host admitido y compose soportado. Observar si aparece en otro compose; no modificar clases/selectores a ciegas.                                                                                         |
| createTracking devuelve 401            | JWT ausente/inválido/expirado o configuración apunta a otro backend.                                        | Ver estado del popup, reloj y dominio del worker. Reactivar con licencia válida. Backend valida firma; Activated local no garantiza autorización. No imprimir Authorization.                                                              |
| Activation falla                       | Código inválido/no almacenado, licencia expirada/revocada, cupos o backend no disponible.                   | Revisar código de error. Un código de create dry-run no existe en AWS. Usar list/installations y CloudWatch por requestId. Si es 500, revisar acceso del handler a tabla y secreto.                                                       |
| JWT expired                            | TTL agotado; no existe refresh automático.                                                                  | Reactivar con licencia ACTIVE. TTL máximo 86400 segundos y limitado por expiración de licencia; comprobar reloj.                                                                                                                          |
| License revoked                        | Admin cambió estado a REVOKED.                                                                              | Confirmar list. Bloquea activación/reactivación; JWT previo dura hasta exp. Installations puede conservar ACTIVE almacenado, sin contradecir revocación de licencia. No hay un-revoke CLI.                                                |
| Max devices reached                    | Perfiles nuevos, reinstalación o borrado de storage consumieron cupos.                                      | Consultar installations y activeDevices. Reactivar misma instalación no consume otro cupo. MVP no libera dispositivos automáticamente; no editar contadores manualmente.                                                                  |
| Pixel no registra                      | Imagen bloqueada, URL incorrecta, pixel no enviado, UUID/tracking ausente o error de persistencia.          | Revisar HTML recibido de correo propio y URL de respuesta create. Comprobar ruta pixel, status HTTP, Lambda y tabla. Una prueba directa crea un OPEN; anotarlo para no confundirlo con lectura.                                           |
| OPEN no aparece                        | Caché/proxy no hizo nueva request, Refresh no ejecutado, licencia propietaria distinta o error de guardado. | Comparar trackingId, CloudWatch y OPEN en DynamoDB. Pulsar Refresh. Verificar GET autenticado y ownership. No contar aperturas visuales como requests garantizadas.                                                                       |
| Geo unavailable                        | MMDB ausente/corrupta, variable omitida en build, IP privada o no localizable.                              | Revisar empaquetado del asset, path Lambda `/var/task/GeoLite2-City.mmdb` y warning geo sin volcar IP. Build sin variable elimina DB empaquetada. Con DB nueva, rebuild/diff/deploy autorizado. El pixel debe seguir funcionando sin geo. |
| Browser/device Unknown o extraño       | UA vacío, irreconocible o perteneciente a proxy/scanner.                                                    | Comparar metadata del evento en sesión privada. Unknown es un resultado válido; no inferir dispositivo del destinatario.                                                                                                                  |
| Custom domain DNS pendiente            | Zona privada/equivocada, delegación incorrecta, registro previo o propagación.                              | Confirmar ID público de cesaragudelo.com, nameservers, alias A al destino regional y eventos CloudFormation. No crear CNAME conflictivo ni nueva zona.                                                                                    |
| Certificate pending                    | Validación DNS ACM no resoluble o permisos/zone incorrectos.                                                | Revisar DomainValidationOptions y registro de validación en zona pública delegada, estado ACM y eventos CloudFormation. Certificado regional junto al API; esperar propagación. No sustituir por certificado manual.                      |
| CSP errors en Gmail/Outlook            | Avisos del sitio/proveedor o requests hechas fuera del worker.                                              | Identificar URL, origen e initiator exactos; distinguir mensajes del proveedor de errores de la extensión. Revisar worker, permiso del dominio y puente de mensajes. No relajar CSP ni permisos globales para ocultar avisos.             |
| Gmail proxy                            | Gmail descarga/cacha imágenes por infraestructura propia.                                                   | Correlacionar request y evento; IP/UA/geo pueden ser de Google. Reabrir no garantiza otra request; no es fallo del contador.                                                                                                              |
| Outlook CSP warnings                   | Políticas/recursos del sitio o variante compose.                                                            | Revisar si el warning existe sin extensión y si POST/pixel realmente fallan. Si falla extensión, guardar solo URL/estado/initiator sin datos privados y revisar host/worker. No asumir que todo warning impide tracking.                  |
| CLI table missing/not found            | Falta --table, nombre incorrecto, cuenta/región distinta o stack no desplegado.                             | Usar output LicenseTableName, región y perfil correctos. `--table` acepta nombre, no ARN. Confirmar identidad antes de escribir.                                                                                                          |
| CLI license missing / ID inválido      | ID incorrecto o pertenece a otra tabla.                                                                     | Usar `lic_<UUID>` mostrado por create/list. Revoke real es condicionado y no crea registros nuevos; dry-run no verifica existencia.                                                                                                       |
| CLI authentication / permission denied | Sesión AWS expirada o IAM administrativo incompleto.                                                        | Renovar sesión del método establecido. Confirmar identidad; permisos de tabla por comando en README. No conceder Scan a Lambdas ni leer JWT secret para administrar.                                                                      |
| CLI network error / throttling         | Conectividad o límite de capacidad/peticiones.                                                              | Verificar red/región y reintentar lecturas más tarde. Scan consume lecturas de toda tabla aunque filtre; no ejecutarlo en bucle. Tras timeout de escritura, verificar list; revoke es repetible, create podría haber creado licencia.     |
| Lista CLI incompleta                   | Error después de una página o cambios concurrentes durante Scan.                                            | Código de salida 1/sin Complete significa salida parcial. Reintentar tras resolver error; no usar Scan como snapshot transaccional.                                                                                                       |
| 429 / latencia                         | Throttling HTTP API o carga de dependencias/GeoLite2.                                                       | Revisar métricas API/Lambda y configuración 5 requests/s, burst 10. Reducir concurrencia de pruebas; evaluar DB real y cold starts antes de cambiar límites.                                                                              |

Una solicitud al pixel no verifica lectura humana. Prefetching, antivirus/scanners,
Apple Mail Privacy Protection, proxies corporativos, VPN y caché pueden explicar
OPEN tempranos, ubicación inesperada o conteos que no coinciden con aperturas humanas.
No intentar corregir estos efectos borrando eventos o alterando contadores.
